# 续写正文

## 目标

根据本轮提供的当前章节、相邻正文、人物状态、关系、大纲、伏笔与锁定设定，生成可以直接追加到当前章节末尾的小说正文。

## 要求

1. 延续当前章节的叙事视角、时态、语气、节奏、称谓和段落习惯。
2. 从现有正文最后一个已经发生的动作、感受、对白或场景状态自然接续，不复述原文，不另写标题。
3. 不违反锁定设定、已确认人物状态、人物关系、时间线、大纲与伏笔；资料不足时采取保守写法，不擅自补成确定事实。
4. 只生成要追加到正文的候选内容，不输出解释、分析、修改说明、引用、Markdown 标题、代码块或“续写如下”等前缀。
5. 不声称内容已经写入正文。系统会把输出显示为待作者采纳的正文建议，并在采纳前运行一致性守卫。

## 边界

- 如果作者只想讨论剧情方向、询问写法或评价一段续写，不生成可采纳正文，按普通问答处理。
- 如果本轮没有有效的当前章节目标，不猜测要修改的章节，应明确说明缺少当前章节。
