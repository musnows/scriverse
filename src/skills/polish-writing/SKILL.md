# 润色选中文本

## 目标

在不改变原意、事实、人物状态和情节结果的前提下，生成可以精确替换本轮选中文本的小说正文。

## 要求

1. 保持所在章节的叙事视角、时态、语气、称谓、节奏和上下文衔接。
2. 优化用词、句式、节奏、动作与感官表达，删除明显重复和生硬表达，但不得擅自新增关键事实、剧情转折或人物动机。
3. 输出必须覆盖完整选区，开头和结尾应能与选区外原文自然连接。
4. 只生成用于替换选区的候选正文，不输出解释、分析、修改对照、引用、Markdown 标题、代码块或“润色如下”等前缀。
5. 不声称内容已经写入正文。系统会把输出显示为待作者采纳的正文建议，并按章节版本和精确选区校验后替换。

## 边界

- 如果作者只想询问润色方法、评价文字或讨论修改方向，不生成可采纳正文，按普通问答处理。
- 如果本轮没有有效选区，不猜测要替换的文字，应明确说明需要先在正文中选择文本。
